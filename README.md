# Data Science Portfolio
Welcome to my Data Science Portfolio! A summary of my projects in the data field can be found here.

### [🌎 Life Expectancy and Health/Economic Predictors](Life-Expectancy/)
Predicted life expectancy of large populations based on various health and economic factors including polio vaccination coverage, alcohol consumption, GDP per capita, and economic development status. Extracted and transformed raw data, built and tested multiple regression models, and produced data visualizations to represent findings, all using R.

### [🦠 Covid-19 in Vermont](Covid-19-Vermont/)
Analyzed Covid-19 trends and the effects of state-specific public health policies. Extracted and transformed raw data, conducted a series of hypothesis tests, and produced data visualizations to represent findings, all using R. 

### [👩‍🔬 Gender Wage Gap in STEM Occupations](STEM-Wage-Gap/)
Analyzed the gender-specific disparity in salary and education in Science, Technology, Engineering, and Mathematics fields. Extracted and transformed raw data, and produced data visualizations to represent basic findings, all using R.
